# Security Policy

## Supported Versions

This repository is maintained as a portfolio project and modular frontend development workflow experiment. Security-related updates and dependency maintenance are reviewed periodically as the project evolves.

## Reporting a Vulnerability

If you discover a security issue, vulnerability, or sensitive exposure related to this repository, please report it responsibly by contacting:

ciscorendon213@gmail.com

Please avoid publicly disclosing security-related findings until the issue has been reviewed and addressed.

## Scope

This project is currently:
- A static frontend portfolio deployment
- Hosted through GitHub Pages
- Built using a custom Node.js and Gulp-based workflow

No sensitive user authentication, payment processing, or private database systems are currently implemented within this repository.

## Third-Party Services

This project may utilize third-party services including:
- Google Tag Manager (GTM)
- Google Analytics 4 (GA4)
- GitHub Pages
- CDN-hosted frontend assets

These services maintain their own independent security and privacy policies.

## Best Practices

The project aims to follow modern frontend development best practices related to:
- dependency management
- frontend performance
- accessibility
- SEO
- secure deployment workflows
- repository organization
- responsible disclosure practices
